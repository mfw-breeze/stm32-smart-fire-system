# 硬件与接线

## 器件清单

| 器件 | 型号 | 作用 | 注意 |
|---|---|---|---|
| 主控 | STM32F103C8T6 最小系统板 | 采样 / 判定 / 显示 | 72MHz，64KB Flash |
| 烟雾传感器 | MQ-2 模块 | 烟雾 / 可燃气体，模拟输出 | **需要预热 30s 以上**，读数才稳定 |
| 温湿度传感器 | DHT11 模块 | 温度 0~50°C ±2°C，湿度 20~90% | 单总线，两次读取间隔 ≥1s |
| 继电器模块 | 5V 单路（光耦隔离） | 驱动 5V 水泵 | 触点侧**独立供电**，不要从板子取电 |
| 显示屏 | 0.96" OLED（SSD1306，I2C） | 显示烟雾值 / 基线 / 温湿度 / 状态 | 软件 I2C |
| 蜂鸣器 | 有源蜂鸣器模块 | 声光报警 | 有源，给电平就响 |
| LED | 板载 PC13 + 外接 PC14 | 状态指示 | 低电平点亮 |
| 按键 | 2 个轻触 | 预留（消音 / 手动喷水） | 上拉输入，按下为低 |

## 引脚分配

| 功能 | 引脚 | 模式 | 说明 |
|---|---|---|---|
| MQ-2 模拟输出 | **PA1** | `GPIO_Mode_AIN` | ADC1_IN1，12 位，读 8 次求平均 |
| DHT11 DATA | **PB15** | 推挽输出 / 上拉输入（切换） | 单总线时序，需要精确延时 |
| 按键 1 | **PB1** | 上拉输入 | 按下为低 |
| 按键 2 | **PB11** | 上拉输入 | 按下为低 |
| 蜂鸣器 | **PB0** | 推挽输出 | 高电平响 |
| 继电器 | **PB13** | 推挽输出 | 高电平吸合（注意你的模块是否低电平有效） |
| LED1（报警） | **PC13** | 推挽输出 | 低电平点亮 |
| LED2（运行） | **PC14** | 推挽输出 | 低电平点亮 |
| OLED SCL | **PB8** | 开漏输出 | 软件 I2C |
| OLED SDA | **PB9** | 开漏输出 | 软件 I2C |
| 串口 TX | **PA9** | 复用推挽 | USART1，115200 8N1，输出 CSV |
| 串口 RX | **PA10** | 浮空输入 | 预留（上位机下发指令） |

## 供电

```
USB 5V ──┬── 继电器模块 VCC（线圈）
         ├── 水泵电源（独立 5V，电流可达 1A）
         └── MQ-2 加热丝（约 150mA）

3.3V ────┬── STM32 / OLED / DHT11
         └── MQ-2 逻辑供电（部分模块支持 3.3V）
```

**三个必须注意的点**：

1. **共地**：水泵电源、继电器、STM32 必须共地，否则 ADC 读数会乱跳。
2. **MQ-2 预热**：上电后加热丝要 30 秒才稳定，这期间的读数**全部丢弃**（代码里有 `Warming up...` 倒计时）。
3. **继电器触点干扰**：吸合/断开会引起电源波动，所以代码在动作后 `Delay_ms(50)` 并丢弃 2 次采样。

## 干扰下的实测现象

| 操作 | 现象 |
|---|---|
| 打火机放气（不点燃）靠近 | 烟雾值 2 秒内从 1262 升到 3000+，温度不变 → 进 `WARNING`，不喷水 ✅ |
| 打火机点燃后靠近 | 烟雾值 + 温度同时上涨 → 从 `WARNING` 升级到 `FIRE`，继电器吸合 ✅ |
| 空调出风口直吹 | DHT11 温度 10 秒内掉 2~3°C，`temp_bad` 不触发（只判升温）✅ |
| 继电器吸合瞬间 | ADC 出现 1~2 帧尖峰，被"连续 8 次确认"滤掉 ✅ |
